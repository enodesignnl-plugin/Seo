# RAWZA — logo's ronde 3

Het woordmerk van concept A uit ronde 1, ongewijzigd, met een klein blad-icoon erboven:

- **Logo 1 — Saffraan uit Herat**: drie bladeren met drie saffraandraden (rood accent).
- **Logo 2 — Het kiemblad**: twee bladeren uit één steel met een lapisblauwe ster als zaadje.

Open `index.html` in een browser. SVG-bestanden (champagne en walnoot) staan in `svg/`.
Gegenereerd met `rawza-brand-exploration/tools/build-v3.cjs`.
