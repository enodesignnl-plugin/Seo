# RAWZA — typografie, ronde 4

Twee woordmerken, alleen letters:

- **Richting A — Refined Signature** (`RAWZA`): de klassieke hoofdletters uit ronde 1, verfijnd. De R-staart is korter en loopt licht omhoog uit, de A heeft een inscriptie-snavel en de W is gekruist.
- **Richting B — Expressive Editorial** (`Rawza`): een nieuwe Didone-letter met grote x-hoogte, bolle druppels aan de a's, een R met spitse voet en één ligatuur (wz).

| Bestand | Inhoud |
|---|---|
| `rawza-direction-a-wordmark.svg` | Richting A, één groep per letter (`letter-R`, `letter-A-1`, `letter-W`, `letter-Z`, `letter-A-2`) |
| `rawza-direction-b-wordmark.svg` | Richting B (`letter-R`, `letter-a-1`, `letter-w`, `letter-z`, `letter-a-2`) |
| `rawza-typography-comparison.html` | Presentatie: naast elkaar, drie kleurstellingen, klein formaat, details |
| `tools/` | Generator: `npm install && npm run build` |

De woordmerken zijn met code getekend, niet gebaseerd op een lettertype. De presentatie gebruikt Cormorant Garamond en Jost (SIL OFL) alleen voor de uitleg.
