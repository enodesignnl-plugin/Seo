# RAWZA — woordmerken v3

Verfijning van de twee richtingen uit `typography-v2/` (die map is ongewijzigd).

| Bestand | Inhoud |
|---|---|
| `rawza-direction-a-v3.svg` | Richting A, Refined Signature (`RAWZA`). Groepen `letter-R`, `letter-A-1`, `letter-W`, `letter-Z`, `letter-A-2` |
| `rawza-direction-b-v3.svg` | Richting B, Expressive Editorial (`Rawza`). Groepen `letter-R`, `letter-a-1`, `letter-w`, `letter-z`, `letter-a-2` |
| `rawza-comparison-v3.html` + `.css` | Presentatie: pure typografie, kleuren, formaten, inspectie (v2 tegenover v3), website-koppen, beoordeling |
| `fonts/` | Alleen voor de presentatie: Cormorant Garamond, Bodoni Moda, Jost (SIL OFL 1.1, licenties bijgevoegd) |
| `tools/` | Generator: `npm install && npm run build` (leest voor de inspectie ook `../typography-v2/tools`) |

De woordmerken zijn als vectorvormen met code getekend en niet gebaseerd op een lettertype. Elke letter is één pad in een eigen groep; gaten zijn samengestelde paden; effen zwart, transparante achtergrond, geen tekst, fonts, filters, maskers of transformaties.
